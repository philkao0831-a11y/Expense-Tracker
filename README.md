# Expense-Tracker
一個輕量級的 Python 互動式記帳工具。透過無窮迴圈持續收集使用者的日常消費項目與金額，並運用「串列包字典」的巢狀資料結構妥善保存每一筆明細，最終一鍵結算總花費並列出完整帳單。
核心功能:
-連續記帳模式：支援不限筆數的連續輸入，並具備防呆設計（輸入大小寫 Q 皆可隨時安全結束記帳）。
-結構化資料儲存：將每筆消費的「項目名稱」與「金額」打包成獨立字典，並依序歸檔至串列中。
-自動結算與明細表：結束輸入後，系統會自動加總所有開銷並條列式印出清晰易讀的消費明細。

使用技術: Python 3

核心語法：
-巢狀資料結構：串列 (List) 搭配字典 (Dictionary) 儲存多筆結構化紀錄。
-while True 無窮迴圈與 break 流程控制。
-for 迴圈走訪資料並進行數值累加 (+=)。
-字串防呆處理 (.lower()) 與 f-string 排版輸出。
